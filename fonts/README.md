# Fontes

Arquivos `.woff2` (subconjunto latin) servidos localmente, sem CDN:

- `inter-latin-wght-normal.woff2` — Inter variável (400–700), de `@fontsource-variable/inter`.
- `poppins-latin-600-normal.woff2`, `poppins-latin-700-normal.woff2` — Poppins, de `@fontsource/poppins`.

Licença: SIL Open Font License 1.1 (Inter © The Inter Project Authors; Poppins © Indian Type Foundry).
Os pacotes `@fontsource*` são `devDependencies` usadas apenas como origem dos arquivos; nada é carregado de `node_modules` em produção.
